# Homify – Real Estate Frontend

Homify is a fully responsive real estate website frontend built using Next.js, React, and Tailwind CSS. It focuses on a fast UI, smooth user experience, and a modern design.
## 🚀 Tech Stack

* **Next.js** – File-based routing aur optimized performance ke liye
* **React** – Component-based architecture
* **Tailwind CSS** – Fast utility-first styling

## ✅ Features

* Fully responsive layout (Mobile-first design)
* Modern hero section with strong CTAs
* Popular properties, featured listings, testimonials
* Contact form section
* Reusable UI components (cards, buttons, sections)
* Fast loading images with `next/image`

## 📁 Project Structure

```
homify/
│
├── public/               # Static images and assets
├── components/           # Reusable UI components
├── app/                  # Next.js app router pages
├── assets/               # images and icons
└── package.json          # Project dependencies
```

## ⚙️ Installation

```bash
npm install
npm run dev
```

App local environment me run hogi:

```
http://localhost:3000
```

## 🛠 Usage

* Components ko reusable tarike se banaya gaya hai.
* Tailwind CSS classes se fast UI build hota hai.
* `app/` folder pages aur routing handle karta hai.

## ✅ Optimization Notes

* `next/image` optimized images use kare
* Reusable cards aur layout components banaye gaye hain
* Tailwind jit (just-in-time) se fast development
